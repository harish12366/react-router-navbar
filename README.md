# React Router Navbar

A simple React application demonstrating client-side navigation using React Router DOM.

## Features

- Navigation using React Router
- Home, About, Services, and Contact pages
- Shared layout using MainLayout
- Nested routing with Outlet
- Active navigation link highlighting using NavLink
- Responsive navbar styling
- Clean and simple UI

## Technologies Used

- React
- JavaScript
- React Router DOM
- HTML
- CSS
- Vite

## Installation

1. Clone the repository.
2. Install dependencies:

   npm install

3. Start the development server:

   npm run dev
